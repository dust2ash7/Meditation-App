# Upload these three files to finish rain-beds

Replace stub `script.js` and add the two recorded beds.

## Files

| Local file | GitHub path |
|---|---|
| `script.js` | `/script.js` |
| `stillpoint-rain.mp3` | `/audio/stillpoint-rain.mp3` |
| `stillpoint-fall.mp3` | `/audio/stillpoint-fall.mp3` |

## GitHub website

1. Open https://github.com/dust2ash7/Meditation-App/upload/rain-beds
2. Drop the three files. For the MP3s, GitHub keeps the filename; then click the file and use Edit file path to put them under `audio/` **or** upload from the `audio` folder page: https://github.com/dust2ash7/Meditation-App/upload/rain-beds/audio
3. Commit to **`rain-beds`**, not `main`.
4. Open a PR: https://github.com/dust2ash7/Meditation-App/compare/main...rain-beds

After the files exist, merge the PR. Pages will pick up `stillpoint-v21`.
